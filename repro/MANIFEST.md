# Manifest

Generated reproducibility and supporting-material bundle for `github.com/juhokoskela/llm-survey`.

## Supplement

- `supplement.md` - post-freeze and post-draft diagnostics, classification chronology, numerical acceptance rules, threshold results, welfare/evidence alignment, navigation and attrition checks, and multiplicity results.

## Analysis code

- `analysis/analysis.py` - reproduces the frozen population-averaged ordinal GEE analyses, sample filters, sign and joint tests, multiplicity corrections, carryover analyses, post-freeze expertise diagnostics, headline descriptive statistics, and Figures 1-4 from the private completed-response CSV.
- `analysis/clmm_primary.R` - reproduces the pre-specified N=538 cumulative-link mixed model and the low-English, categorical-tier, early-completion, and collapsed-top-category sensitivities using `ordinal::clmm2` with AGHQ7.
- `analysis/adversarial.py` - reproduces the post-draft analyses from an authorized private dump, with private outputs restricted to a new directory outside the repository.
- `analysis/third_review_checks.py` - third-review demographic adjustments, H3/H5 interactions and separation checks, response profiles, mind-background construction, welfare overlap, self-report alignment, and sample audits.
- `analysis/review_checks.py` - second-review comprehension, interpretation, secondary-predictor, descriptive, and separation checks; callable within the full workflow or independently against a private audit.
- `analysis/clmm_floor_checks.R` - all neutral/empathy exclusion mixed-model attempts, with numerical acceptance status.
- `analysis/test_review_checks.py` - complete/quasi-separation detection, text aggregation, and private-output boundaries.
- `analysis/bundle_manifest.py` - regenerates hashes from an explicit distributable-file list.
- `analysis/export_dump.ts` - validates and converts the local dump using the application exporter.
- `analysis/ordinal_models.py` - shared GEE fitting with identified treatment coding and numerical acceptance checks.
- `analysis/clmm_diagnostics.R` - quadrature, alternative starts, and quality/knowledge sensitivity models, with inner and outer diagnostics separated.
- `analysis/test_ordinal_models.py` - reference-coding invariance, collinearity rejection, factual-score parsing, and private-output protection tests.
- `analysis/attrition.py` - reproduces the post-consent completion funnel from the private production JSON dump.
- `analysis/prepare_qualitative_coding.py` - creates blinded, randomized F7 and F8 coding sheets from the private completed-response CSV.
- `analysis/qualitative_agreement.py` - calculates per-code agreement and creates a disagreement sheet for adjudication.
- `analysis/test_qualitative_workflow.py` - tests blinding, deterministic randomization, spreadsheet-formula neutralization, and agreement calculations.
- `analysis/requirements.txt` - Python dependencies.
- `analysis/README.md` - commands, frozen model details, and numerical notes.

## Instrument and study plans

- `materials/survey_instrument.md` - standalone extract of the full v0.6 instrument.
- `materials/survey-master-plan.md` - full pre-data master plan dated June 1, 2026.
- `materials/pre_data_analysis_plan.md` - shorter pre-data confirmatory/exploratory analysis extract. This was private, not publicly preregistered.

## Coding and analysis records

- `materials/qualitative_codebook_v1.md` - frozen multi-label F7/F8 codebook and independent-coding procedure.
- `materials/data_dictionary.md` - documented private CSV schema and privacy notes.
- `materials/quantitative_freeze_v2.md` - frozen claims, model specifications, sensitivities, and inferential guardrails used for drafting.
- `materials/literature_verification_freeze.md` - verified cornerstone-literature notes used to constrain novelty claims.
- `materials/revision_history.md` - chronology of post-draft audits and review rounds and what each added or corrected.

## Aggregate results

- `results/post-review-summary.json` - selected aggregate outputs generated by `analysis/adversarial.py`, including post-draft effect estimates, threshold checks, paired counts, and welfare/navigation sensitivities. No respondent records or free text are included.
- `results/clmm-diagnostics.csv` - aggregate estimates and acceptance status from `analysis/clmm_diagnostics.R`; rejected fits have no inferential CI or p-value.

- `results/clmm-floor-diagnostics.csv` - all four floor-exclusion attempts, with inferential intervals only for accepted fits.

`SHA256SUMS` records hashes for the explicit distributable-file list in `analysis/bundle_manifest.py`. It excludes itself, hidden metadata, and caches. Run `python repro/analysis/bundle_manifest.py` from the repository root after changing bundle contents.

## Not included

- participant-level datasets;
- raw production database dump;
- completed-response CSV.

The deployed survey web-application source is stored at the repository root, outside this reproducibility bundle.
